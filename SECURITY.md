# Security

This repository contains public usage examples only. It does not contain the
private Actor implementations.

Never commit an Apify token, API key, password, or customer data. Set
`APIFY_TOKEN` through the local environment as described in the README.

To report a suspected secret exposure or security issue, contact the repository
owner privately through GitHub rather than opening a public issue. Include the
affected path and commit, but do not include the secret itself.
